## ① 수치·단위·논리 오류

- **[치명] §2 팜유 — `1511.90`으로 “SBO−CPO 스프레드”를 측정할 수 없음.**  
  CPO는 조유인 `1511.10-0000`이고, 필수로 지정한 `1511.90-1000/-9000`은 팜올레인·RBD 등 비조유 품목이다. 정제·분획 프리미엄, 운임, 관세가 섞인 수입단가를 CPO 가격으로 취급하면 스프레드의 상품 규격과 가격 기준이 달라진다. 이 데이터로 산출 가능한 것은 정제 대두유–정제/분획 팜유 수입단가 차이이지 SBO−CPO 스프레드가 아니다.

- **[높음] §1 — 대두유 HSK 코드 목록에서 `1507.10-9000(기타 조유)`이 누락됨.**  
  `1507.10`은 식품용·바이오디젤용 외 “기타” 세번도 확인해야 하는데, 표와 “6코드 × 누락국 6” 작업 범위에 포함되지 않았다. 무역량이 없더라도 코드 자체를 제외 판정과 함께 남겨야 하며, 현재의 “확정 6코드”는 1507 세번 전체를 포괄한다는 표현으로는 부정확하다.

- **[높음] §1·§7 — 현재 HSK 세번을 2010~2026 전체에 그대로 적용한 것으로 보이며 연도별 코드 개편을 처리하지 않음.**  
  HSK2021·2022·2023·2024 자료를 혼용하면서 2010년부터의 누적량을 제시했지만, 코드별 시행일과 구·신 세번 concordance가 없다. 현행 코드가 존재하지 않던 연도의 API 무응답을 수입 0으로 해석하거나, 과거 물량을 누락할 위험이 있다.

- **[높음] §2 유채유 — `1514.11-0000`을 “압착용”으로 설명한 것은 공정 단계가 잘못됨.**  
  `1514.11`은 이미 압착·추출된 저에루크산 **조유**다. 착유·크러시 설비의 원료는 유채씨(HS 1205)이며, 조유는 일반적으로 정제 공정 투입물이다. “CJ 겸용 압착설비” 근거로 이 코드를 선정하면 원료곡과 조유 흐름이 혼동된다.

- **[높음] §2 — HS6 Comtrade 수치로 HSK10 하위 코드의 물량·국가를 확정함.**  
  `1511.90`은 팜올레인·스테아린·기타를, `1512.19`는 해바라기유·잇꽃유의 여러 하위 세번을, `1514.19`는 정제유·기타를 함께 포함한다. 따라서 HS6 수치만으로 `1511.90-1000/-9000`, `1512.19-1010`, `1514.19-1000`의 물량이나 상위국을 “실측”했다고 할 수 없다.

- **[높음] §1 — 베트남의 MY24/25 전체 대두유 비중을 `.1010` 누락분의 근거처럼 연결함.**  
  132,764t·27.5%는 한 개 마케팅연도의 전체 대두유 국가 비중인 반면, `.1010`의 64%·3.3억kg은 2010~2026 HSK10 누적 차액이다. 기간과 코드 해상도가 모두 달라 베트남이 `.1010` 누락분을 구성한다거나 여섯 코드 모두의 우선 수집국이라는 결론은 나오지 않는다.

- **[높음] §1·§6 — 21kg을 “무역 부재”로 분류한 것은 0과 비제로를 혼동함.**  
  `AR 21kg`은 미미하더라도 명백한 비제로 관측이다. 특히 §6에서 “0 보존 vs 미보고 구분”을 원칙으로 제시하므로, 이는 “부재”가 아니라 “비경제적 소량/이상치 후보”로 분류해야 한다.

- **[높음] §6 — 코드별 단 한 해의 API 표본으로 코드 실존·무역 부재를 확정할 수 없음.**  
  한 해의 무응답은 해당 연도 무역 없음, 코드 미시행, API 누락, 조회 조건 오류를 구별하지 못한다. 코드 유효기간 확인과 복수 연도·전 세계 합계 조회 없이 “무역 부재 코드”를 확정하면 잘못된 제외가 발생한다.

- **[높음] §3 — `1201.90-2000`의 389.6%를 근거로 희소 무역을 예상하고 수작업 제외한 논리가 불완전함.**  
  제시된 세율이 기본세율인지 WTO 양허세율인지, TRQ 밖 세율인지, 특정 연도·협정 세율인지 명시되지 않았다. TRQ·용도세율·FTA 적용 가능성을 배제하지 않은 상태에서 명목 세율만으로 실제 수입 희소성을 판단할 수 없다.

- **[참고] §1 러시아 — 비율과 증가율의 기준이 없음.**  
  “5,500t, 3.2배 증가, 비중 1.6% 이하”에서 비교 기준연도 물량과 비중 분모가 제시되지 않았다. “3.2배 증가”도 전년의 3.2배인지, 320% 증가인지 모호하다.
