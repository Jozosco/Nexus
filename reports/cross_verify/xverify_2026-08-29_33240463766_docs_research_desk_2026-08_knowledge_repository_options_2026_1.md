## ① 수치·단위·논리 오류

- **[높음] 자산 건수의 모집단이 서로 맞지 않는다.**  
  요약은 2,175건인데 인덱스는 2,227행으로 **52행 차이**가 난다. 인덱스 1행이 원문 1건이라면 요약 커버리지는 최대 `2,175 / 2,227 = 97.7%`다. 중복 행·요약 미생성 원문·비PDF 행 여부가 설명되지 않아 “원문 PDF와 1:1” 및 조인 가능 범위를 확인할 수 없다.

- **[높음] “문서 ~5천”이라는 규모 산정의 단위가 혼재돼 있다.**  
  실제 적재 구조에 명시된 검색 객체는 `2,175 요약 + 300+ 결정 + 66 문서 + 152 용어 = 2,693+`다. 원문 PDF 2,175건을 별도 문서로 더해야 약 4,868건이 되지만, 정규화 구조에는 PDF 본문이 입력 대상으로 표시되지 않는다. 문서·결정·용어·원문을 동일 단위로 합산했는지 불명확하다.

- **[높음] 제안 스키마로는 EvidenceSpan의 “page+원문 인용 100% 일치”를 보장할 수 없다.**  
  명시된 필드는 문서 ID·유형·날짜·태그·엔티티·본문·출처 경로뿐이며 페이지, 원문 인용문, 문자 오프셋, 청크 ID, 원문 체크섬이 없다. MEMORY 결정과 일반 md에는 페이지 자체가 없을 수도 있다. 계약 문서가 존재하는 것과 적재·검색 단계에서 이를 자동 검증하는 것은 별개다.

- **[높음] 외부 SaaS의 “잔존자산 0·이관 시 승계 불가”는 과도한 단정이다.**

- **[참고] “인덱스 CSV가 RAG의 절반을 완성”했다는 50% 평가는 산식이 없다.**
