# Databento GLBX.MDP3 — CBOT 대두유 선물(ZL) 일봉

## ⚠️ 현재 이 폴더에 **사용 가능한 목표변수 데이터가 없습니다**

`*.BROKEN` 두 파일은 **날짜가 파괴된 산출물**입니다. 열지 말고, 어떤 파서도 읽지 않습니다.

```
price_date
1970-01-01 00:00:00.000000000
1970-01-01 00:00:00.000000001   ← 행 번호가 나노초로 해석된 결과
```

원인은 A-102로 규명·수정 완료입니다. `pd.concat(parts, ignore_index=True)`가
`ts_event` DatetimeIndex를 폐기하고, 이어지는 `reset_index()`가 RangeIndex를
`index` 컬럼으로 만들면서 epoch 나노초로 해석됐습니다.

**코드는 고쳐졌지만 디스크의 산출물은 수정 전 것**입니다. 파일이 존재한다는 사실이
곧 유효하다는 뜻이 아니라는 점(A-050·A-118의 반복 원인)을 표면화하기 위해
확장자를 `.BROKEN`으로 격리했습니다.

## 복원 방법 — 재실행이 유일한 정공법

날짜를 파일 내부에서 복원할 수는 없습니다. `ts_event`가 남아 있지 않고,
행 순서만으로는 휴장일을 특정할 수 없습니다. CBOT 동일 거래소 계열(TE 대두 4,086일)로
역산하는 방법도 검토했으나 **행 수가 4,051로 일치하지 않아** 하루만 어긋나도
이후 전 구간이 밀리므로 채택하지 않았습니다.

> GitHub Actions → **Historical Analysis Pipeline** → `connector=databento` 실행

재실행 산출물은 `scripts/ingest_databento_bo.py`의 다음 검증을 통과해야 합니다.

| 검증 | 기준 |
|---|---|
| 날짜 범위 | 2010–2026 (1970 검출 시 즉시 실패) |
| 종가 범위 | 5–200 USc/lb |
| 롤 중복 | 같은 날짜 복수 계약 → 거래량 최대 계약 채택 |

## 이 데이터가 없으면 막히는 것

- **G2 가격밴드** — 예측 대상 자체가 없음
- **G1 동인분석** — 종속변수가 없어 중요도 산출 불가
- **feature mart 거래일 달력** — 현재 영업일(Mon–Fri)로 대체 중이며,
  CME 휴장일이 섞여 있어 정식 산출물로 쓸 수 없음
