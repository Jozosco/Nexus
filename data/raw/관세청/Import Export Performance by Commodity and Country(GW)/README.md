# 관세청 — 품목별 국가별 수출입실적 (GW)

관세청 제공 HS코드 기반 수출입 통관 실적 (2010~2026, 16개년).

- 집계: 수입=CIF USD, 수출=FOB USD · 중량=순중량(kg)
- 갱신: 월별(매월 15일경, 정정·취하 반영)
- HS 단위: 2·4·6·10 단위 집계
- 대두유 HS: 1507.10(.1000/.2000), 1507.90(.1010/.1020/.1090/.9000)
- 파서(예정): scripts/ingest_customs_gw_xlsx.py

## 파일 명명 규칙 (A-184 · 2026-08-19)

| 파일 | 출처 | 갱신 |
|---|---|---|
| `{국가}.xlsx` | **조정자 수동 업로드분(기준선)** — 스크립트가 읽지도 쓰지도 않음 | 수동 |
| `{국가}_API.xlsx` | `scripts/ingest_customs_gw_xlsx.py`의 data.go.kr API 수집분 | Historical 실행 시 자동(재개 지원) |

- 두 파일은 **동일 형식**(연도 시트 × 월 행 × 5지표 열)이며 같은 폴더에 나란히 둔다.
- 분석·검증 시 병합 원칙: **원본 우선 · `_API`는 원본에 없는 품목·국가·연도만 보완**.
- 재개: `_API` 파일의 연도 시트 수가 기대치에 못 미치면 다음 실행이 그 쌍만 재수집한다
  (완전본은 건드리지 않음). 전량 재수집은 `CUSTOMS_FORCE_REFRESH=true`.
