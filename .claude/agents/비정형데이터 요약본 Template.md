# 비정형 PDF 통합분석용 요약 보고서 템플릿

> 버전: 1.0  
> 작성 기준일: 2026-08-11  
> 목적: 농산물·식품원료·무역·정책·기후 관련 PDF를 동일한 기준으로 요약하여 국가·품목·기간 간 통합분석에 활용한다.

---

## 0. 작성 원칙

1. **사실, 전망, 해석을 구분**한다.
   - `사실`: 문서에 명시된 과거·현재의 관측값 또는 사건
   - `전망`: 문서가 제시한 미래 수치·방향·시나리오
   - `해석`: 작성자가 도출한 인과관계 또는 한국 관점의 시사점
2. 모든 핵심 주장에 **문서 ID, 페이지, 근거 문장 또는 표 번호**를 붙인다.
3. 인과관계는 가능한 한 **원인 → 시장 메커니즘 → 수급/가격 결과**로 기록한다.
4. 원문에 없는 값은 추정하거나 대체하지 않는다. 확인되지 않은 항목은 `미확인`, `문서 내 언급 없음`, `판단 불가`로 표시한다.
5. 동일 사건이 여러 페이지에서 반복되더라도 전망 지표 수를 중복 집계하지 않는다.
6. 상승·하락 방향은 반드시 **대상 지표 기준**으로 기록한다. 예: 생산량 증가는 `공급 ↑`이지만 일반적으로 `가격 ↓` 압력이다.
7. 수치에는 원문 단위와 정규화 단위를 함께 기록한다. 환산한 경우 환산식과 배율을 남긴다.
8. 직접 구매·판매 명령이 아니라, 분석 근거와 검토가 필요한 시사점으로 작성한다.

## 9. 전망 추세 판정

### 9.1 방향성 지표 집계표

| 지표 ID | 국가 | 품목 | 원인/신호 | 최종 대상 | 방향 | 강도 | 신뢰도 | 기간 가중치 | 중복 그룹 | 근거 |
|---|---|---|---|---|---:|---:|---:|---:|---|---|
| `SIG-001` | `[국가]` | `[품목]` | `[신호]` | `[가격/공급/수요]` | `[+1/-1/0]` | `[1–3]` | `[0.00–1.00]` | `[0.5/0.75/1.0]` | `[그룹 ID]` | `[p.00]` |

**방향 코딩**

- `+1`: 대상 지표의 상승 신호
- `-1`: 대상 지표의 하락 신호
- `0`: 중립·방향 불명확·상충
- 가격 전망을 집계할 때 `공급 증가`는 보통 가격 `-1`, `수요 증가`는 보통 가격 `+1`로 변환하되, 문서가 반대 메커니즘을 명시하면 해당 근거를 우선한다.

### 9.2 집계 결과

| 항목 | 결과 |
|---|---:|
| 상승 지표 수(U) | `[N]` |
| 하락 지표 수(D) | `[N]` |
| 중립/혼재 지표 수(N) | `[N]` |
| 방향성 지표 합계 | `[U + D]` |
| 순방향 지수 | `[(U - D) ÷ (U + D)]` |
| 신뢰도 가중 점수 | `[Σ(방향 × 강도 × 신뢰도 × 기간 가중치)]` |
| 최종 추세 | `[상승 우세 / 하락 우세 / 균형·혼조 / 판단 불가]` |

**최종 문장 형식**

> **전망 추세: `[하락 우세]` (상승 지표: `[27]` / 하락 지표: `[42]` / 중립·혼재: `[N]`; 신뢰도 가중 점수: `[값]`)**

**판정 규칙**

1. `U > D`이면 `상승 우세`, `D > U`이면 `하락 우세`로 표시한다.
2. `|U-D| ≤ max(2, 방향성 지표 합계의 5%)`이면 `균형·혼조`로 표시한다.
3. 방향성 지표가 3개 미만이거나 핵심 근거 신뢰도가 낮으면 `판단 불가`를 우선한다.
4. 단순 개수와 신뢰도 가중 점수가 반대이면 `혼조`로 표시하고 이유를 서술한다.
5. 동일 사건·동일 수치·동일 인과경로의 반복 언급은 하나의 지표로 집계한다.

### 9.3 추세 해석

> `[어떤 국가·품목·변수가 상승/하락 지표를 주도했는지, 단기와 중기의 방향이 다른지, 결과를 반전시킬 조건이 무엇인지 3–5문장으로 작성]`

- [ ] 분석 페이지 수와 커버리지 계산이 맞다.

- [ ] 모든 핵심 주장에 페이지 또는 표·그림 근거가 있다.
- [ ] 인과관계가 원인 → 메커니즘 → 결과로 연결되어 있다.
- [ ] 공급·수요·가격 방향을 서로 혼동하지 않았다.
- [ ] 전망 기간과 시나리오 전제가 명시되어 있다.
- [ ] 국경 간 교역의 출발국·도착국·품목·물량·조건이 기록되어 있다.
- [ ] 한국 관점에서 CIF/CFR, 환율, 리드타임, 공급국 집중, 대체 가능성을 검토했다.
- [ ] 키워드가 통제어휘에 매핑되고 근거 페이지가 있다.
- [ ] 전망 지표의 중복을 제거했다.
- [ ] 상승/하락 개수와 신뢰도 가중 점수를 함께 확인했다.
- [ ] 상충 정보와 데이터 공백을 숨기지 않았다.
- [ ] 원문에 없는 수치나 확률을 임의 생성하지 않았다.
