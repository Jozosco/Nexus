# 방법론 — 예측 모델 (G1 · G2 · G3)

세 목표를 **Champion–Challenger 포트폴리오**로 운영합니다: 단일 거대 모델을 확정하지
않고, 검증 가능한 통계 모델(Champion)을 기본으로 두고 딥러닝(Challenger)은 사전 등록된
승격 규칙을 통과할 때만 채택합니다. 상세: `.claude/rules/modeling.md`

## 공통 원칙

- **외부 데이터 전용**(D-021) — 내부 S&OP/ERP는 학습·검증·피처 어디에도 미투입
- **as-of 시점 정합** — 발표일 이전 정보 사용 금지(용어집 참조)
- **walk-forward 검증만** — 무작위 분할 금지 · 모든 전처리는 fold 내부 재적합
- **Baseline 필수** — last value·seasonal naive·ETS를 못 이기면 승격 없음
- **stress slice 별도 보고** — 사건 구간을 이상치로 제거하지 않음
- 예측 지평: **1 · 5 · 20 · 60 거래일 직접 예측**(60일 ≈ 3개월 조달 지평)

## G1 — 변수 중요도·경보 (어떤 동인이 가격을 움직이는가)

| 단계 | 방법 | 이유 |
|---|---|---|
| 변수 선택 | **Elastic Net** | LASSO 단독은 공선성 하에서 동행 변수 중 하나만 남겨 불안정 — L1+L2 혼합으로 제어 |
| 중요도 순위 | LightGBM/XGBoost + **SHAP** | 비선형 기여도 분해 — 설명 가능성 |
| 교차 확인 | Permutation importance | SHAP과 삼각 검증 |
| 선행 관계 | Granger 인과(Bonferroni 보정) | 다중검정 오류 통제 |
| 충격 반응 | 국소투영(Local Projections) | 시차별 반응 크기·지속기간 |

중요도는 전체 기간 하나가 아니라 **horizon × 레짐(Bear/Neutral/Bull)별**로 분해.
⚠️ SHAP은 기여도이지 인과가 아님 — 인과 주장은 시맨틱 레이어의 검증된 엣지만.
발행: **3계층** — 일별 경보판(임계 초과 시에만) · 주별 정규판(금) · 월별 심층판(WASDE 후).
**+ 과거 유사 시기 실측 참조(D-051 재정립)**: 변수의 표준화 지수가 현재와 같은 구간이던
과거 거래일들의 이후 실측 분포를 참조로 제공(`analogue_g1.py` — 과거 관측 요약까지만,
전망·확률 주장 아님 A-191).

## G2 — 확률 가격 밴드 (가격이 어느 범위에 있을 것인가)

출력 계약: 점 예측이 아니라 **P10/P25/P50/P75/P90 + 구간 + 상승확률 + 임계 초과확률**.

| 층 | 방법 | 역할 |
|---|---|---|
| 평균 경로 | SARIMAX | 외생변수 효과·소표본 강건 |
| 비선형 분위수 | Quantile LightGBM | 분위수 직접 예측 |
| 변동성 | EGARCH-X | 변동성 군집·비대칭·꼬리 |
| 구간 보정 | **EnCQR** | 분포 무가정 커버리지 보장 — 레짐별 실측 커버리지 보고 |

훈련은 컴퓨트 중립 배치 잡(2026-09-02 개정 — Azure 폐지에 따라 ETL#2 Python 또는 Dev EC2, mlflow 추적·S3 아티팩트) · VMD류 전체 분해는 누수 위험으로 기본 제외.
운영 번역 계층: 관세청 실측 CIF 기반 **원화 도착가 참고 밴드** + 4축 조달 대안 — 단
확률 밴드 주장은 분위수 모델 가동 후에만(현재는 규모감 참고).

## G3 — 레짐·조달 신호 (지금 어떤 국면인가)

Markov 레짐 전환(확률 출력) + G2 분포 결합 → Bear/Neutral/Bull 확률 + 구매/보류 참고
신호. **+ 3-시뮬레이션(D-051 재정립)**: ①현시점 구매 ②사전 그리드 대안 시점 ③분할
구매의 근사 손익(per-MT regret) — 설계 정본은 Annals of OR 2026 VoI(선도+옵션+현물
3채널 포트폴리오). **모든 신호는 인간 승인 게이트(HITL)를 통과해야 하며 AI가 자율 실행하지 않음** —
P&L 영향 추정·신뢰 범위 없이는 출력 금지, 몬테카를로 분산 >20%면 HIGH UNCERTAINTY 격상.

## Challenger 승격 규칙 (사전 등록)

딥러닝(LSTM·N-BEATSx·TFT·PatchTST 등)은 동일 fold에서 4개 horizon 중 3개 개선 +
커버리지 5%p 이내 + stress slice 비열화 + DM 검정 통과 시에만 Champion 교체.
