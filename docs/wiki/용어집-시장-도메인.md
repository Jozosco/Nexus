# 용어집 — 시장·도메인

보고서에 등장하는 대두유 시장·정책·무역 용어. (한국어 표준 표기는 `.claude/rules/korean_style.md` §2.3 준수)

## 수급·가격

| 용어 | 설명 |
|---|---|
| **대두유 (SBO)** | Soybean Oil. 조대두유(crude, HS 1507.10)와 정제 대두유(refined, HS 1507.90)로 구분 |
| **압착 (Crush)** | 대두를 부수어 대두유(약 20%)와 대두박(meal)으로 분리하는 공정. **압착량이 곧 대두유 공급의 상류** |
| **압착 마진 (Crush margin)** | (대두유+대두박 판매가) − 대두 매입가. 보드 크러시 기준은 부셸(60lb)당 유 11lb·박 44lb — 실측 추출률은 2020/21 이후 ~20%(12lb)로 상승 |
| **재고사용비율 (STU)** | Stocks-to-Use Ratio. 기말재고 ÷ 총사용량 — 수급 타이트함의 표준 지표. WASDE 계열 핵심 변수 |
| **WASDE** | USDA 세계 농산물 수급 전망(월간, 통상 매월 10~12일 발표). 모델에는 **실제 발표일 이후에만** 반영(as-of 규율) |
| **마케팅연도 (MY)** | 작물 연도. 미국 대두는 9월~익년 8월, 대두유는 10월~9월. 달력연도와 혼용 금지 |
| **레짐 (Regime)** | 시장 국면(Bear/Neutral/Bull). G3가 확률로 추정하며, G1 변수 중요도도 레짐별로 분해 |
| **CPO / SBO−CPO 스프레드** | CPO=조팜유. 대두유−팜유 가격차 — 대체 수요 전환의 신호. ⚠️2020년 이후 두 시장의 공행성이 구조적으로 붕괴(farmdoc 실증)해 **평균회귀를 가정하지 않음** |

## 무역·조달

| 용어 | 설명 |
|---|---|
| **CIF / CFR / FOB** | Incoterms. CIF=운임·보험 포함 도착가(관세청 수입단가 기준), CFR=운임 포함, FOB=본선 인도. **관세청 CIF 단가 ≠ 시장 CFR 호가**(판독 규율) |
| **basis** | 선물가격 대비 현물(지역) 프리미엄/할인. 우리는 실측 호가 부재로 관세청 CIF−CBOT 차이를 **'내재 잔차층'**으로 역산(월별·후행 근사) |
| **CBOT ZL** | 시카고 대두유 선물 — G1/G2의 목표변수 원천(`CBOT_BO_CLOSE`=정산가 기준) |
| **HS / HSK** | 국제 품목분류(6자리) / 한국 세번(10자리). 대두유는 1507.10-1000(식품용 조유) 등 6개 코드 |
| **TRQ** | 저율관세할당. 한국 식용 대두 TRQ 자율증량 중단(2026) = 수입 물량 하방 요인 |
| **DJVE** | 아르헨티나 수출 판매 등록 — **등록 ≠ 선적**(판독 규율) |
| **아르헨 수출세** | 대두 계열 수출세(현행 24%) — 공식 환율보다 실질적인 공급 신호. Decree 423/2026으로 2028년까지 15%로 단계 인하 예정 |

## 바이오연료·정책 (미국)

| 용어 | 설명 |
|---|---|
| **RFS / RVO** | 미국 재생연료 의무제도 / 연도별 의무 물량. 2026~27 BBD RVO가 사상 최대(+67/70%) — **미국 대두유의 내수 전용화 압력의 근원** |
| **BBD / RD / FAME** | 바이오매스 기반 디젤 / 재생디젤 / 바이오디젤. RD 붐(2021~)이 대두유 수요 구조를 바꿈 |
| **RIN / RIN 뱅크** | 재생연료 크레딧(컴플라이언스 화폐). D4=바이오디젤 계열. **RIN 뱅크(이월 재고)가 2027년 소진 전망 = 무완충 국면**(상방 꼬리위험) |
| **SRE** | 소규모 정유소 면제 — 면제분 재배분(70%) 여부가 실효 의무량을 좌우 |
| **half-RIN** | 수입 연료·원료의 크레딧 절반 인정 규정 — 철회가 아니라 **2028년 시행 예고**. 시행 시 수요 압력이 국내(대두유)로 재집중되는 스위치 |
| **45Z / CI** | 청정연료 생산 세액공제 / 탄소집약도(gCO2e/MJ). CI가 낮을수록 크레딧 상승(최대 $1.75/gal) — 원산지·공정별 원료 프리미엄의 배경 |
| **HEFA / SAF / ATJ** | 수소처리 지방산 공정 / 지속가능항공유 / 알코올 항공유. **대두유 HEFA가 SAF 시장 48~62%** — 도로(RD)에 이은 두 번째 수요 엔진 |

## 지속가능성·규제

| 용어 | 설명 |
|---|---|
| **DCF** | Deforestation- and Conversion-Free. 삼림파괴·전용 무관 소싱 — Cargill 남미 직소싱 99% 수준 |
| **EUDR** | EU 삼림파괴 규정 — 수요 측(유럽) 압력으로 트레이더 관행을 바꾸는 경로 |
| **모라토리엄** | 아마존 대두 모라토리엄 — 2006년 이후 신규 개간지 대두 구매 금지 협약 |
