# 용어집 — 데이터·인프라

파이프라인·리포트에 등장하는 데이터 용어. 상세: `docs/research_desk/2026-08/glossary_mart_asof_duckdb_2026_08_19.md`

## 시점 정합 (as-of) — 프로젝트 최우선 규율

| 용어 | 설명 |
|---|---|
| **as-of 원칙** | 모델의 t일 입력 = `available_at ≤ t`인 가장 최근 값. **"그날 실제로 알 수 있었던 정보만 쓴다"** — 미래 정보 누수(look-ahead) 차단의 핵심 |
| **available_at** | 값이 시장에 공개된 시각. WASDE 8월호는 대상월이 아니라 **발표일(8/12) 이후**에만 가시화 |
| **event_time / release_time** | 값이 가리키는 시점 / 공식 발표 시각. FRED는 ALFRED로 **실측 게시일** 확보 |
| **vintage (개정 이력)** | 같은 관측치의 발표 회차. 개정치는 덮어쓰지 않고 회차별 보존 — WASDE만 회차 보유, 94개 지표는 개정 오염 표기 후 민감도 검증 대상 |
| **장중 확정 시각** | 일 단위 as-of로 못 잡는 누수: CBOT 마감(14:20 ET) **이후** 확정되는 지표(VIX 등)는 1일 지연 적용 |

## 데이터 파이프라인

| 용어 | 설명 |
|---|---|
| **Feature Mart** | 거래일×지표 격자에 as-of 정렬된 **모델 입력 테이블**(`data/gold/`). 4,000+행 × 1,400+지표. 값충돌 시 자동 선택 금지(하드 실패) |
| **DuckDB / ASOF JOIN** | 서버 없는 분석 DB — "그 시점까지의 최근값" 조인을 내장. parquet 직접 질의·이관 시 자산 손실 0 |
| **parquet** | 열 지향 데이터 파일 포맷 — 파이프라인 표준 저장 형식 |
| **커넥터 / 인제스터** | 외부 API 수집기(`src/pipeline/connectors/`) / 수동 업로드 파일 파서(`scripts/ingest_*.py`) — 재실행 가능(결정적) |
| **백필 (Backfill)** | 과거 구간 일괄 수집(2010~). 실시간 전용 소스(AIS·Perplexity 프록시)는 백필에서 제외 |
| **BACKFILL_MODE** | 백필 실행 표시 환경변수 — 실시간 전용 수집을 자동 건너뜀 |

## 품질·검증

| 용어 | 설명 |
|---|---|
| **DQSOps (C-08 게이트)** | 5차원 가중 품질 점수(정확도 30·완전성 25·일관성 20·신선도 15·왜도 10) — PASS≥0.70. **필수 산출물 누락도 차단**(fail-closed) |
| **fail-open / fail-closed** | 실패를 통과로 위장 / 실패 시 명시 차단. 프로젝트는 3회의 fail-open 사고 후 **fail-closed + 정직 표기**를 규율화 |
| **E1 '서명된 무소식'** | 일별 서명 스탬프 — 게이트 상태·경보 수·검증 상태·런 ID를 명시해 **'침묵'과 '전부 검사했고 이상 없음'을 구분** |
| **교차검증 원장** | 모든 산출물의 GPT-5.6 교차검증 판정 누적 기록(`docs/research_desk/cross_verify_log.md`) |
| **EvidenceSpan / S-5** | 모든 주장에 원문 발췌·출처 보존 의무 — 요약이 근거를 대체하지 않음 |
| **4-라벨** | CONFIRMED / INFERENCE / DATA GAP / NOT COMPARABLE — 사실과 추론의 명시 구분(D-047 판독 규율) |

## 검증 지표 (G2 계열)

| 용어 | 설명 |
|---|---|
| **P10/P50/P90** | 분위수 — "실제값이 이 아래일 확률 10%/50%/90%". G2는 점 예측이 아닌 **확률 밴드**를 출력 |
| **EnCQR** | 앙상블 conformal 분위수 회귀 — 예측구간이 명목 커버리지(80%면 실제로 80%)를 지키도록 보정 |
| **empirical coverage** | 실측 커버리지 — 레짐별로 별도 보고(평시에만 잘 맞는 모델 차단) |
| **walk-forward** | 시간 순서를 지키는 검증 — 무작위 분할 금지(시계열 철칙) |
| **stress slice** | 2012 가뭄·2018 미중·2020 팬데믹·2022 러우 등 사건 구간 별도 평가 — 충격을 이상치로 제거하지 않음 |
