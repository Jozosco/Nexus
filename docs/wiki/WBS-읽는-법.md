# WBS 읽는 법

주간 WBS 파일(`reports/WBS_{MMDD}.xlsm`)의 구조와 읽는 방법. Excel에서 열어 확인하며,
간트 막대는 XLGantt 매크로 실행 시 렌더링됩니다.

## 파일 운영 주기

- **매주 월요일 KST 14:00** — 자동 초안 생성(직전 WBS 복사 + 주간 실적 집계 +
  기한 경과·임박 작업 🔴/🟡 표시). 진척률은 자동으로 확정하지 않음
- **보고 시점** — C-01 검토를 거친 **확정본**(예: `WBS_0826.xlsm`)을 발행.
  파일명 숫자가 기준일(월/일)

## 시트 구성

| 시트 | 내용 |
|---|---|
| **Schedule** | 본체 — WBS 계층·기간·진척률·간트 |
| **금주_작업범위** | 이번 주(월~일) 작업 목록: 구분·작업·담당·기한·상태 |
| **지연위험_등록부** | 위험 ID(R1~)·위험도(🔴🟡🟢)·예상 지연·원인·대응 방안 |
| **데이터_유무료** | 데이터 소스별 비용 구분(무료/유료/승인 대기) |
| Progress · Calendar 등 | XLGantt 템플릿 보조 시트(수식 자동) |

## Schedule 시트 읽기

### 계층 (WBS 열)

```
1        프로젝트 루트 (전체 진척률)
1.1      Phase 1: 데이터 기반 정비
1.1.x    개별 작업 — [분류] 접두: [데이터수집] [처리·정제] [전처리] [분석] [시각화] [아키텍처]
1.2      Phase 2: G1 리포트 자동화  ★ 8/31
1.3      Phase 3: G2 가격밴드 Preview ★ 9/10
1.4      Phase 4: 시맨틱·아키텍처 (일정 비의존)
```

**★ 표시 = 하드 마일스톤.** ⚠️ 표시 = 지연위험 항목(지연위험_등록부에 상세).

### 주요 열

| 열 | 의미 |
|---|---|
| 시작일*/완료일* | **계획** 기간 (간트 막대의 기준) |
| 실제 시작일/완료일 | 실측 기간 |
| **실적*** | 진척률(0~1). **C-01이 보수적으로 산정** — 100%는 검증 통과까지 완료된 것만. "코드 작성 완료·검증 대기"는 100%가 아님 |
| 비고 | 관련 결정 ID(D-xxx)·이슈 상태 |

### 진척률 해석 주의

- Phase 진척률은 하위 작업의 요약이지만 **단순 평균이 아님**(작업 크기 가중) —
  루트 70%가 "70% 시점"이 아니라 "핵심 기반은 끝났고 분석·모델 단계 진행 중"으로 읽는 것이 정확
- 상태가 "검증 대기"인 항목은 구현 완료여도 실적을 보수적으로 유지 —
  파이프라인 프로젝트에서 "돌아간다"와 "검증됐다"는 다름(fail-closed 원칙)
