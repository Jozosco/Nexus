## ① 데이터 수집

### 1-1. 외부 API 자동 수집 (커넥터 12종)
- **목적**: 시세·환율·운임·기후·수급·수입통계·지정학 데이터를 매일 자동으로 받아 오기
- **입력**: 각 기관의 공개 API (열쇠가 필요한 곳은 별도 보관된 키 사용)
- **출력**: `data/raw/*.parquet` (자동 실행의 첨부 파일로 생성)
- **실행 위치·주기**: 자동 실행 `external_data_refresh.yml` · 평일 05:30(한국시간)
- **현재 상태**: **가동**. 최근 실행(2026-09-09)에서 20개 작업 전부 성공
- **관련 문서**: `src/pipeline/connectors/` · `.claude/rules/data_pipeline.md`
- **인수 후 첫 행동**: 최근 3회 실행 결과를 훑어 "성공했지만 0건"인 계열이 없는지 확인

### 1-2. 수동 업로드 파일 파서
- **목적**: API로 못 받는 자료(관세청 수출입 실적, 유가·운임 이력, 미국 수급·무역 통계, 거래소 월별 거래량)를 사람이 올린 엑셀에서 읽어 표준 형식으로 바꾸기
- **입력**: `data/raw/관세청/`, `data/raw/Trading Economics/`, `data/raw/USDA/`, `data/raw/ICE/`
- **출력**: `data/raw/*_historical.parquet` (예: `customs_gw_uploads_historical.parquet` 174파일·77,253행)
- **실행 위치·주기**: 자동 실행 `historical_backfill.yml`(수동 시작) 및 일별 준비도 단계에서 재구성
- **현재 상태**: **가동**. 관세청 업로드본 통합 파서는 2026-09-07 신설, 9/8 추가 업로드분까지 반영
- **관련 문서**: `scripts/ingest_*.py` · `docs/research_desk/2026-09/customs_gw_upload_review_2026_09_07.md`
- **인수 후 첫 행동**: 미완료 목록 2건 확인 — 팜핵 조유 10개 파일이 빈 서식 상태(재업로드 필요)

### 1-3. 비정형 문서 판독·요약 (보고서 PDF)
- **목적**: 미국·국제기구의 시장 보고서 PDF를 읽어 요약과 신호 표시를 붙이고, 월별 숫자 계열로 바꾸기
- **입력**: `data/raw/USDA/FAS/GAIN/`, `data/raw/FAO/` (문서 2,200건 이상)
- **출력**: 요약 md 파일 + `data/raw/unstructured_signals_historical.parquet` (자동 실행 시 생성 — 새로 받은 저장소에는 없을 수 있음)
- **실행 위치·주기**: 자동 실행 `unstructured_analysis.yml` (수동 시작 — 비용·시간 때문에 매일 돌리지 않음)
- **현재 상태**: **완료(증분 운영)**. 판독 실패 0건, 열람 불가 문서도 0건
- **관련 문서**: `scripts/summarize_pdfs.py` · `scripts/build_unstructured_timeseries.py`
- **인수 후 첫 행동**: 새 문서를 올린 경우에만 이 실행을 수동으로 한 번 돌리기(전량 재판독 금지)

## ② 품질·시점 게이트

### 2-1. 데이터 품질 게이트
- **목적**: 그날 모인 데이터가 분석에 쓸 만한지 점수로 판정하고, 미달이면 파이프라인을 멈추기
- **입력**: 그날 수집된 모든 parquet 파일
- **출력**: `reports/data_quality/` 판정 파일 + 실행 요약의 통과/경고/불합격 표시
- **실행 위치·주기**: 일별 자동 실행의 검사 단계
- **현재 상태**: **가동**. 5개 항목 가중 점수(정확도·완전성·일관성·신선도·분포), 0.70 이상 통과
- **관련 문서**: `src/pipeline/validators/c08_dq_validator.py` · `docs/wiki/방법론-데이터-품질.md`
- **인수 후 첫 행동**: 불합격이 나오면 "데이터가 나쁜 것"인지 "파일이 아예 안 온 것"인지부터 구분

### 2-2. 시점 정합(as-of) 검사
- **목적**: **그날 실제로 알 수 없었던 정보를 모델이 보는 일**을 구조적으로 막기 (예: 8월 수급 보고서는 발표일 이후에만 사용)
- **입력**: 모든 지표 행의 5개 시간 항목(사건 시각·발표 시각·가용 시각·개정 회차·수집 시각)
- **출력**: 검사 통과/위반 목록 — 위반이 있으면 그 자리에서 중단
- **실행 위치·주기**: 저장 직전 자동 부여 + 일별 검사 단계
- **현재 상태**: **가동**. 최근 실행 기준 위반 0건
- **관련 문서**: `src/pipeline/asof.py` · `scripts/validate_asof.py` · `docs/wiki/용어집-데이터-인프라.md`
- **인수 후 첫 행동**: 새 데이터 소스를 붙일 때는 반드시 발표 규칙을 이 파일에 먼저 등록

### 2-3. 분석용 표 만들기 + 준비도 판정
- **목적**: '날짜 × 지표' 격자표를 만들되, 같은 시점에 값이 두 개면 **임의로 고르지 않고 실패**시키기
- **입력**: 검사를 통과한 parquet 전체
- **출력**: `data/gold/` (격자표와 데이터 계약 파일)
- **실행 위치·주기**: 일별 자동 실행의 준비도 단계
- **현재 상태**: **가동**. 값 충돌 48,789건 → 0건, 지표 1,400종 이상
- **관련 문서**: `src/features/build_feature_mart.py` · `scripts/data_readiness.py`
- **인수 후 첫 행동**: "값 충돌로 실패"가 뜨면 지표 이름에 지역·국가 구분이 빠졌는지 먼저 의심

## ③ 분석·보고

### 3-1. 핵심 변인 분석 (G1)
- **목적**: 대두유 가격 움직임과 함께 움직인 지표를 순위로 뽑고, 기준을 넘은 지표에 경보 붙이기
- **입력**: 분석용 격자표(`data/gold/`)
- **출력**: 변인 순위표·경보 목록 + 정식 보고서(한/영 HTML·PDF)
- **실행 위치·주기**: 일별 자동 실행의 분석 단계
- **현재 상태**: **가동(정식 2026-08-31)**. 방법론 확장과 경보 기준 재조정은 진행 중(진척 낮음)
- **관련 문서**: `src/forecasting/variable_importance_g1.py` · `.claude/rules/modeling.md`
- **인수 후 첫 행동**: 경보 기준 5개 중 2개가 아직 평가 코드 없음 — 개선 계획 문서에서 우선순위 확인

### 3-2. 과거 유사 시기 실측 참조
- **목적**: 지표가 지금과 같은 구간이던 **과거 날짜들**을 찾아, 그 이후 1주/1개월/3개월 실제 변화 분포를 보여 주기
- **입력**: 분석용 격자표의 표준화 지수와 과거 수익률
- **출력**: 브리프의 "과거 유사 시기 실측 참조" 블록 + 월별 보고서 절
- **실행 위치·주기**: 일별 분석 단계에서 함께 산출
- **현재 상태**: **가동**. 표본이 8회 미만이면 "산출 보류"로 정직하게 비웁니다
- **관련 문서**: `src/forecasting/analogue_g1.py` · `tests/test_analogue_g1.py`
- **인수 후 첫 행동**: 화면 문구에 "전망·확률 주장"이 섞이지 않았는지 확인(금지어 자동 검사 있음)

### 3-3. 일일 브리프 발행
- **목적**: 위 결과를 실무자가 한 화면에서 읽도록 웹 페이지 1장으로 조립
- **입력**: 변인 순위·경보·유사 시기·일별 뉴스 신호·참고 도착가 범위
- **출력**: `reports/pipeline/latest/g1_daily_brief_latest.html` (최신 1장) + 실행 첨부 파일
- **실행 위치·주기**: 매 영업일 자동
- **현재 상태**: **가동**. 외부 라이브러리·스크립트 없이 그리므로 사내망에서도 열립니다
- **관련 문서**: `src/reporting/daily_brief.py` · `docs/handover/00_개요_비전문가용.md` §3
- **인수 후 첫 행동**: 브리프를 열어 "미수집"으로 비어 있는 블록이 몇 개인지 세어 보기

### 3-4. 3계층 발행 + 서명 스탬프
- **목적**: 매일 전부 다시 계산해 순위가 흔들리는 것을 막고, 발행 주기를 성격에 맞추기
- **입력**: 분석 결과와 게이트 상태
- **출력**: 일별 경보판(기준 초과 시) · 주별 정규판(금) · 월별 심층판(수급 보고서 발표 후) + `data/processed/signed_daily_stamps.csv`
- **실행 위치·주기**: 일별 자동 실행이 발행 모드를 스스로 판정
- **현재 상태**: **가동**. 서명 기록의 경보 집계 결함은 2026-09-02 수정 완료
- **관련 문서**: `scripts/signed_daily_stamp.py` · `docs/research_desk/2026-09/g1_report_trust_and_cadence_2026_09_02.md` §4
- **인수 후 첫 행동**: 서명 기록 마지막 5줄을 보고 매일 한 줄씩 쌓이고 있는지 확인

### 3-5. 참고 도착가 범위 · 조달 대안 비교
- **목적**: 선물 가격을 한국 도착 기준 금액대로 옮겨 **규모감**을 주고, 시점·물량·조건 등 대안 축을 비교
- **입력**: 관세청 실측 수입단가, 선물 종가
- **출력**: `reports/market/landed_cost_band_*.md`, `reports/market/procurement_alternatives_*.md`
- **실행 위치·주기**: 브리프와 함께 산출
- **현재 상태**: **가동(제한적)**. 확률 밴드가 아니라 **참고 범위**이며 화면에 한계를 항상 표기
- **관련 문서**: `src/forecasting/landed_cost.py` · `src/forecasting/procurement_alternatives.py`
- **인수 후 첫 행동**: 이 숫자로 "지금 사라/기다려라"를 결론짓지 않도록 문구를 그대로 유지

## ④ 시맨틱·비정형

### 4-1. 용어·인과 관계 관리 (시맨틱 레이어)
- **목적**: 용어를 하나로 통일하고, "무엇이 무엇에 영향을 준다"는 관계를 검증된 것만 쓰도록 관리
- **입력**: 용어 사전(152개)·조사 문헌 근거
- **출력**: `src/semantic/entities.yaml`, `ontology.yaml`, `causal_chains.md`
- **실행 위치·주기**: 문서 변경 시 자동 검사(`scripts/validate_semantic_layer.py`)
- **현재 상태**: **진행**. 인과 관계 24건·근거 46건, 도메인 확인 작업이 남아 있음(진척 50%)
- **관련 문서**: `docs/wiki/용어집-시장-도메인.md`
- **인수 후 첫 행동**: 검증되지 않은 관계를 브리프 문구에 인용하지 않도록 상태 표시(검증됨/후보) 확인

### 4-2. 비정형 신호 시계열화
- **목적**: 보고서 요약에 붙인 신호 표시(수출 규제·기상이변·압착 등)를 월별 숫자 계열로 바꿔 분석에 쓰기
- **입력**: 요약 md와 색인 파일
- **출력**: 신호 계열 parquet (2,500행 이상·18지표)
- **실행 위치·주기**: 비정형 자동 실행 시
- **현재 상태**: **가동**
- **관련 문서**: `scripts/build_unstructured_timeseries.py`
- **인수 후 첫 행동**: 새 문서 반입 후 이 단계를 돌렸는지 확인(안 돌리면 계열이 과거에 머무름)

### 4-3. 일별 뉴스·전문 매체 수집
- **목적**: 해협·정책·운임 같은 사건형 정보를 매일 모아 브리프에 붙이고 영구 보관
- **입력**: 실시간 검색 응답 7분류 + 전문 매체 소식 6~9계열
- **출력**: `data/processed/unstructured_daily_signals.csv` (매일 누적)
- **실행 위치·주기**: 일별 자동 실행에 포함
- **현재 상태**: **가동**
- **관련 문서**: `scripts/daily_unstructured_digest.py`
- **인수 후 첫 행동**: 파일 마지막 날짜가 어제인지 확인 — 멈춰 있으면 수집 계열 점검
