# Nexus 개요 — 비전문가용

> **읽는 사람**: 이 서비스를 처음 넘겨받는 관리자·신규 분석 담당자.
> 통계나 머신러닝 지식 없이 읽을 수 있게 쓴 문서입니다.
> 작성 기준일: 2026-09-09 · 근거 자료 경로는 각 절 끝에 표기.

---

## 3분 요약

1. **무엇**: 수입 대두유(콩기름)를 언제 사는 것이 좋은지 **판단을 돕는 정보**를 매일 자동으로 만들어 주는 시스템입니다. 사는 행위는 하지 않습니다.
2. **어떻게**: 매 영업일 아침 5시 30분(한국시간)에 외부 공개 데이터 9계열을 자동 수집하고 → 품질 검사 3단계를 통과시키고 → 분석해서 → **일일 브리프(웹 페이지 1장)** 를 발행합니다.
3. **핵심 산출물**: 일일 브리프 1장. 오늘 가격, 눈여겨볼 변수, 기준을 넘은 항목(경보), **과거에 지금과 비슷했던 시기에 실제로 어떤 일이 있었는지**, 공급 경로 상태, 다가오는 일정이 한 화면에 있습니다.
4. **신뢰의 방식**: 맞출 자신을 강조하지 않고 **"오늘 무엇을 검사했고 무엇이 없는지"를 매일 서명해 남기는** 방식입니다. 이상이 없는 날에도 "검사했고 이상 없음"이라는 기록(서명된 무소식)을 남깁니다.
5. **현재 상태**: 1단계 목표(G1)는 **2026-08-31 정식 가동**. 2단계(G2, 확률 가격 범위)는 설계 확정·구현 중. 3단계(G3, 구매 시점 시뮬레이션)는 설계 단계입니다.

## 1. 이 시스템은 무엇을 하는가

식품 제조사가 원료로 쓰는 **대두유를 수입**할 때, 가격이 오르내리는 이유는 매우 많습니다.
미국·아르헨티나의 작황, 팜유 같은 대체유 가격, 배 운임, 환율, 미국의 바이오연료 정책,
호르무즈 해협 같은 물류 길목의 사고 — 실무자 한 사람이 이 모든 것을 매일 볼 수는 없습니다.

Nexus는 이 데이터를 대신 매일 모아서 **세 가지**를 알려 줍니다.

| 알려 주는 것 | 쉬운 말로 |
|---|---|
| **핵심 변인** | "오늘 대두유 가격을 설명하는 데 가장 크게 관여한 지표는 이것들입니다" |
| **경보** | "이 지표가 평소 범위를 벗어났습니다 — 눈여겨보세요" |
| **과거 유사 시기 실측 참조** | "이 지표가 지금과 같은 수준이던 과거 날짜들 이후, 실제 가격은 1주/1개월/3개월 뒤 이렇게 움직였습니다" |

세 번째가 이 시스템의 성격을 가장 잘 보여 줍니다. **미래를 맞히겠다는 예측이 아니라,
"과거에 실제로 그랬다"는 관측의 요약**입니다. 화면에도 그 한계를 매번 표시합니다.

## 2. 매일 아침 05:30에 무슨 일이 일어나는가

대두유 선물 시장이 한국시간 오전 7시에 열리기 때문에, **개장 전에 정보가 준비되도록**
평일 오전 5시 30분에 자동 실행됩니다. 사람이 버튼을 누르지 않습니다.

```
① 수집 (9계열)
   시세·환율 / 운임 / 작황·수급 / 기후 / 대두유 선물 종가 /
   지정학 / 생산·수출 / 관세청 수입통계 / 지리·재난 정보
   + 뉴스·전문 매체 요약(비정형)
        ↓
② 품질 게이트 3종  ← 하나라도 '불합격'이면 여기서 멈춥니다(고의로 멈춤)
   ⑴ 데이터 품질 점수(정확도·완전성·일관성·신선도·분포)
   ⑵ 구조·이상치 검사
   ⑶ 자동 테스트(파이썬 테스트 30건 내외)
        ↓
③ 준비도 판정 + 분석용 표 만들기
   "분석에 꼭 필요한 데이터가 오늘 다 있는가?"를 먼저 판정하고,
   통과하면 '날짜 × 지표' 격자표(Feature Mart)를 만듭니다
        ↓
④ 분석 · 브리프 발행
   핵심 변인 순위 → 경보 판정 → 과거 유사 시기 조회 → 일일 브리프 HTML 발행
        ↓
⑤ 서명 스탬프
   오늘의 게이트 상태·경보 수·검증 상태·실행 번호를 한 줄로 기록에 남김
```

**왜 중간에 일부러 멈추나**: 데이터가 빠졌는데 조용히 넘어가면, 그날 브리프는 "이상 없음"처럼
보이지만 사실은 아무것도 못 본 상태가 됩니다. 이 프로젝트는 그런 사고를 세 번 겪은 뒤
**"실패는 반드시 눈에 보이게 멈춘다"** 를 규칙으로 만들었습니다.

*근거: `.github/workflows/external_data_refresh.yml` · `docs/wiki/방법론-데이터-품질.md`*

## 3. 산출물을 어디서 어떻게 읽는가

### 3.1 일일 브리프 — 화면 구성

맨 위에 **신뢰 스트립**이 있고, 그 아래 본문 8블록이 이어집니다.

| # | 블록 | 무엇이 있나 | 어떻게 읽나 |
|---|---|---|---|
| 0 | **신뢰 스트립** | 오늘 게이트 통과 여부·경보 수·검증 상태 | 여기가 초록이 아니면 아래 내용을 그대로 믿지 않습니다 |
| 1 | 한눈 요약 | 전 거래일 종가, 참고 도착가 범위, 경보 수, 데이터 적시성 | 오늘의 숫자 4개 |
| 2 | 가격 추세와 핵심 변인 | 최근 90거래일 가격 그래프 + 상위 변인 5개 | 그래프의 급변일에 번호 표시 → 누르면 당시 기사·지표 상태가 열림 |
| 3 | 금일 경보(유의 사항) | 기준을 넘은 지표와 그 근거 | 없으면 "검사된 무소식"으로 표시됩니다 |
| 4 | **과거 유사 시기 실측 참조** | 지금과 같은 상태였던 과거 시기의 이후 1주/1개월/3개월 실제 변화 | 확률이 아니라 "과거엔 이랬다"입니다 |
| 5 | 글로벌 공급 경로 현황 | 산지 4곳 → 한국, 주요 해협 4곳의 상태 표시 | 빨간 점이 켜진 길목을 봅니다 |
| 6 | 지표 스냅샷 | 주요 지표의 최근값·기준일·추세 미니 그래프 | 기준일이 오래됐으면 그 지표는 신선하지 않은 것 |
| 7 | 금일 언론·매체로 보는 시장 추세 | 당일 수집된 뉴스·전문 매체 항목과 원문 링크 | 기사 → 신호 → 인과 경로 연결을 펼쳐 볼 수 있음 |
| 8 | 주목해야 할 일정 | 수급 보고서 발표일, 조달 리드타임 역산일, 정책 발효일 | "언제까지 판단해야 하나"의 달력 |

각 블록에는 **[현황] → [요인] → [전망] → [유의·권고]** 4단 요약 문장이 붙습니다.
데이터가 없으면 꾸미지 않고 **"미수집"**이라고 그대로 씁니다.

### 3.2 '서명된 무소식'이란

경보가 없는 날에 아무 말도 없으면, 받는 사람은 **"평온한 것"과 "시스템이 죽은 것"을 구분할 수 없습니다.**
그래서 이상이 없는 날에도 "오늘 무엇을 검사했고 결과가 어땠는지"를 한 줄 서명으로 남깁니다.

`data/processed/signed_daily_stamps.csv` (날짜 · 판정 · 게이트 · 경보 수 · 준비도 · 검증 · 실행번호)

## 4. 이 시스템이 하지 않는 것 (중요)

| 하지 않는 것 | 이유 |
|---|---|
| **자동 구매·자동 발주** | 모든 조달 판단은 사람의 승인 절차를 거칩니다. 시스템은 참고 신호까지만 (`CLAUDE.md` §6) |
| **"가격이 오를 확률 ○%" 주장** (현재) | 확률 밴드는 2단계 목표(G2)의 산출물이며 아직 가동 전입니다. 지금 화면의 범위는 **참고 범위**이지 확률이 아닙니다 |
| **사내 판매·재고·구매 실적 데이터 사용** | 데이터 양이 부족하고 임시값 비중이 커서, 학습·검증·변수 어디에도 넣지 않기로 결정했습니다(외부 공개 데이터 전용) |
| **대두유 외 원료 확장** | 범위가 대두유로 고정되어 있습니다 |
| **실시간 갱신** | 하루 1회 배치 구조입니다 |

## 5. 목표 G1 / G2 / G3 — 쉬운 설명과 현재 상태

| 목표 | 한 문장 설명 | 지금 상태 |
|---|---|---|
| **G1 — 핵심 변인 + 과거 유사 시기** | "지금 무엇을 봐야 하는가"를 알려 주고, 지금과 닮았던 과거 시기의 실제 결과를 보여 줍니다 | ✅ **2026-08-31 정식 가동**. 자동 실행이 무개입으로 연속 성공(8/31·9/1), 최근 실행(9/9)은 20개 작업 전부 성공. 방법론 확장·경보 기준 재조정은 진행 중 |
| **G2 — 확률 가격 범위** | "앞으로 1일/1주/1개월/3개월 뒤 가격이 어느 범위에 있을 가능성이 큰가"를 확률로 제시 | 🟡 **설계 확정·구현 중**. Preview 목표일 9/10, 진척 15% 수준 |
| **G3 — 구매 시점 3가지 비교** | "지금 살까 / 몇 주 뒤에 살까 / 나눠 살까" 세 가지를 과거 시장가 기준으로 비교해 손익 차이를 보여 줍니다 | 🔵 **설계 단계**. 설계 근거 문헌까지 확정, 구현 미착수 |

세 목표 모두 **인간 승인 게이트**를 전제로 하며, AI가 스스로 실행하는 구간은 없습니다.
