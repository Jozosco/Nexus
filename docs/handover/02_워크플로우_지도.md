## 1. 매일 도는 것 — 일별 사슬

`external_data_refresh.yml` 하나가 **20개 작업 단위**로 이어져 있습니다.

```
[평일 05:30 한국시간 자동 시작]
│
├─ 수집 (동시에 실행 — 하나 실패해도 나머지는 계속)
│   경제지표 · 운임 · 작황수급 · 기후/엘니뇨 · 대두유 선물 종가 ·
│   지정학 · 생산/수출 · 관세청 수입통계 · 지리재난 · 상품가격
│   + 일별 뉴스·전문매체 요약
│         ↓
├─ 수집 요약  (무엇이 몇 건 들어왔는지 표로 정리)
│         ↓
├─ 게이트 ①  데이터 품질 점수        ← 불합격이면 아래가 전부 멈춤
├─ 게이트 ②  구조·이상치 검사
├─ 게이트 ③  자동 테스트
│         ↓
├─ 준비도 판정 + 분석용 격자표 만들기  ← 꼭 필요한 데이터가 없으면 여기서 멈춤
│         ↓
├─ 분석·발행   핵심 변인 → 경보 → 과거 유사 시기 → 일일 브리프
│         ↓
└─ 서명 스탬프  오늘 검사 결과를 한 줄로 기록에 남김
                (사슬 어디에서 멈췄든 이 기록은 남습니다)
```

**중요**: 사슬이 멈추는 것은 고장이 아니라 **설계**입니다. 데이터가 빠졌는데도 브리프를
발행하면 "이상 없음"으로 오해되기 때문입니다.

2. 최신 실행 클릭 → **Summary** 화면에 그날 수집 건수·상위 변인 표가 요약되어 있습니다
