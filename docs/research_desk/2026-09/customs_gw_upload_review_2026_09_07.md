## §2 분석 편입 (완료)

- 신규 파서가 업로드본을 롱포맷(`KCS_{HS10|HS6}_{IMP_USD|IMP_KG|EXP_USD|EXP_KG|BAL_USD}_{국가}`)으로 정규화해
  `data/raw/customs_gw_uploads_historical.parquet`에 저장 — 통합본은 `WORLD`로 분리 보존(국가 합산과 혼입 금지),
  미완결 월 제거, (지표,월) 충돌 시 하드 실패, 시점 정합 5필드 부여(확정치 개정은 vintage).
- 일별 파이프라인의 준비도 잡 재구성 단계(수동 파서 6종)에 7번째로 편입 → 매일 mart 후보에 포함. G1 데이터 현황 표에 항목 등록.
- 향후 수집: API 수집기(6자리·국가 10 고정)와 별개로 업로드본이 정본 히스토리이며, API 수집분은 `_API.xlsx`로 보완(원본 불가침).
  보완 국가 확정 시 파서의 국가 매핑에 코드가 이미 등록돼 있어(UA·HU·TR·CA·SG 포함) 파일만 올리면 자동 편입된다.
