## 1. 목적 — 왜 문헌을 원장으로 만드는가

공유받은 예측 방법론 자료가 스물 건을 넘기면서, "이 논문을 왜 채용했는지 · 왜 배경으로만
두었는지"가 조사 노트 산문 안에만 남아 있었다. 산문은 검색되지 않고 검증되지도 않는다.
그 결과 두 가지 사고가 반복됐다. 하나는 **기록은 '등재 완료'인데 실제 규칙 파일에는 아무것도
없는** 갭이고, 다른 하나는 **원문 없이 판정만 도는** 상태다.

예측 로직 선례 층은 이 둘을 기계로 막는다. 기법과 문헌을 같은 파일에 두고, 문헌이 어떤 기법의
무엇을 정당화하는지 참조로 연결한 뒤, 원문 파일이 디스크에 실재하는지까지 게이트가 확인한다.
**문헌은 기법을 정당화할 뿐 대체하지 않는다** — 판정이 '채용'이라도 승격 게이트를 통과하기
전에는 Champion이 되지 않는다는 규율은 그대로다.

통제 어휘는 파일 상단에 선언한다 — 판정 `채용 · Challenger 검토 대기 · 배경 · 인용 주의 ·

포트폴리오), 결합 계층 1종(뷰 결합 — 설계 동결), 기준선 3종, 심층학습 후보 5종(전부 동결 —

## 4. 새 문헌이 선례가 되는 경로

1. **해시 중복 검사** — 이미 보관된 원문과 바이트가 같으면 재보관하지 않는다(누적 차단 여섯 건).
2. **원문 판독** — `pdf_to_markdown` 경로로 전문을 읽는다. 이미지 기반 PDF는 렌더 판독.
3. **요약·정직 분류** — 우리 도메인·데이터로 재현 가능한가, 기준선 비교가 있는가, 저널 신뢰도는
   어떤가를 따져 판정을 정한다. 추측 채용은 금지이며 '배경'·'인용 주의'도 정당한 결과다.
4. **MP 등재** — `method_precedents`에 추가하고 `applies_to`로 기법을 연결한다. 근거는
   원문 위치(locator)와 짧은 한국어 발췌(quote_ko)를 반드시 함께 적는다.
5. **C13 통과 확인** — 판정 어휘·목표 어휘·id 중복·원문 실존·기법 참조를 게이트가 검사한다.
   판정이 '채용'이면 여기서 끝이 아니라 승격 게이트가 이어진다.

## 5. 게이트 확장과 검증 결과

이번에 게이트에 더한 것은 세 가지다.

- **C13 신설** — 위 5단계의 마지막 관문. 파일 파싱, 어휘 준수, id 중복, 원문 파일의 디스크 실존,
  `applies_to` 참조 실존, 근거 필드 존재를 검사한다. 위반은 기존 검사와 동일하게 집계되고
  `--strict`에서 차단되며, 게이트의 종료 코드 규칙 자체는 바뀌지 않았다.
- **C4 확장** — 지표 바인딩에 이름 규칙(regex) 기반 항목(`structured_patterns`)이 들어올 수 있게
  했다. 항목마다 `pattern`·`regex`(컴파일 가능 여부까지)·`entities`(용어 실존)를 검사하고,
  키가 없으면 조용히 건너뛴다. 도입 전 저장소와 도입 후 저장소 양쪽에서 똑같이 통과한다.
- **C12 보강** — 일별 신호 브리지 검사가 태그를 일반 순회하도록 유지·확인했고, 다이제스트 모듈
  임포트 실패를 의존성 부재 외의 오류까지 흡수하도록 넓혔다. 신규 태그가 추가돼도 코드 변경이
  필요 없다.

함께 일별 신호 레지스트리의 누락도 메웠다. 전문 매체 RSS 열 계열 중 두 계열만 등재돼 있어
나머지 여덟(OFI·GRAIN·미 대두협회·크라이미트폴·AgMarket·Grain Central·TFM·UkrAgroConsult)이
수집돼도 다이제스트에 나타나지 않고 태그 배정 점검에서도 빠지던 상태였다. 이제 수집 소스
정의와 신호 레지스트리가 열 계열로 일치한다.

**검증 결과**(`python scripts/validate_semantic_layer.py --strict`): 위반 0건 · 경고 5건 ·
종료 코드 0. C13 정보 행은 `기법 23종 · 선례 17건 로드 — 채용 4 · 검토 대기 1`. 경고 5건은
전부 이번 변경 이전부터 있던 잔여 갭(용어 사전 미연결 1 · 템플릿 커버리지 4)이며 새로 늘어난
위반은 없다. 일별 지표 태그 미배정 경고는 같은 시점에 진행된 신호 태그 매핑 갱신으로 해소됐다
— 새로 등재한 여덟 계열을 포함해 일별 지표 서른셋이 모두 태그에 배정된 상태를 확인했다.
정형 지표의 이름 규칙 바인딩도 실제로 들어와 C4 확장 검사를 위반 없이 통과한다.
부정 경로도 함께 확인했다 — 판정 어휘 위반,
원문 파일 부재, 끊어진 기법 참조, 목표 어휘 위반, id 중복, 근거 발췌 누락을 각각 정확히
한 건씩 잡아낸다.
