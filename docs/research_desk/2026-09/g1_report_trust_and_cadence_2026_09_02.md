## §1 현행 신뢰 근거 — 무엇이 있고 무엇이 없는가 (정직 판정)

### 1.1 실재하는 근거 4계층 (CONFIRMED)
| 계층 | 장치 | 실측 |
|---|---|---|
| ① 입력 데이터 품질 | 데이터 품질 게이트(정확도 .30·완전성 .25·일관성 .20·적시성 .15·분포 .10 가중, PASS≥0.70·WARNING≥0.50·REJECTED는 파이프라인 차단) · 시점 정합 검사 6종(위반 시 차단) · 준비도 게이트 | 9/1 런: 12종 PASS · 시점 정합 위반 0 · 지표 값충돌 0 |

| ③ 산출 논리 검증 | 외부 LLM 적대 교차검증(수치·누수·인과 과장·재현성) · 서술 계약(필수 캡션·금지어 기계 검증) | 원장 165건 = 판정 106 · **미판정 59** · 누적 치명 95(미해소 2) |
| ④ 발행 무결성 | 서명된 무소식 스탬프(게이트·경보·준비도·검증 원장·런 ID) | 스케줄 런 2연속 전체 초록(8/31·9/1) |

### 1.2 없는 것 (DATA GAP — 숨기지 않음)
- **경보 적중률·오경보율·리드타임·백테스트: 0건.** 경보 이력 자체가 저장소에 없고, 서명 스탬프의 경보 열은
  파일명 날짜 형식 불일치로 **8/26 이후 전부 0으로 오염**돼 있었음(9/1 실경보 2건 발생일에도 "무소식" 커밋).
  → 당일 발견·수정(파일명 태그 매칭 + 회귀 테스트 4건). 과거 6행은 사실 기록이므로 재작성하지 않고 오염 기간을 명시.
- 참고 도착가 범위가 CI에서 매일 "산출 불가"로 강등돼 있었음(관세청 API 당년 분과 분석창 캡 CBOT의 공통 월 0) →
  당일 수정(정산가 전 기간 우선 + API·업로드본 합집합, 테스트 3건). 다음 스케줄 런에서 판정.
- 선언된 임계값 5종 중 **재고사용비율·대두유−팜유 가격 차이 2종은 평가 코드가 없음**(3종만 실평가). 지정학
  지표의 P90 기준은 최신값을 포함한 전 기간 분포라 임계가 매일 이동함.

**결론**: 오늘의 신뢰 근거는 **과정 무결성**(검사했고 누수가 없고 침묵과 무소식을 구분함)이지 **결과 정확도**가
아님. 실무자에게는 이 구분을 그대로 보여 주는 것이 신뢰의 출발점임.

## §2 실무자용 신뢰 지표 — 측정 가능한 6축

| 축 | 지금 측정 가능? | 통계량·창 | 전망 주장 방지 장치 |
|---|---|---|---|
| ① 입력 정확도 | 가능 | 정산가 교차검증 상대오차 중앙값·P99를 **롤링 250거래일**로 상시 + 커넥터별 품질 점수 | 해당 없음 |
| ② 시점 정확도 | 가능 | 시점 정합 위반 0 · 개정 이력 미보존 지표 수(94종) 공개 · 실측 게시일 대비 추정 발표일 오차 | 해당 없음 |
| ③ **경보 사후 성적** | 불가(원장 0) → 9월 구축 | 경보 후 5/20/60일 실측 \|수익률\|이 직전 3년 무조건부 중앙값 이하인 비율(=오경보 근사) · 성숙 경보만 평가(look-ahead 차단) · 간격≥h 에피소드 압축 · 8회 미만 보류 · **규칙 버전** 병기 · 과거 전용 소급 합성 이력을 "실발행 아님" 라벨로 병행 | 방향 적중률 금지 — 변동 크기 분포만 |
| ④ 참조 범위 폭 진단 | 소급 가능 | 60거래일 참고 범위(P10~P90)에 실측이 든 비율 — **월별판 부록 한정·'범위 폭 진단'으로 격하** | 포함율 공표는 확률 밴드 주장이 되므로 의사결정 근거로 쓰지 않음 |
| ⑤ 변인 순위 안정성 | 가능(월별) | 월간 상위 20 Spearman ρ · 부호 안정성 · SHAP/permutation 일치도 | 해당 없음 |
| ⑥ 경보 정합성 | 가능 | G1 경보 수 = 서명 스탬프 경보 수 (불일치 0) | 오늘 결함이 이 축의 부재를 실증 |

브리프 상단 **신뢰 스트립**은 ①②⑥을 매일, ③⑤를 월별로 표시한다.

## §4 배포 일정 현황과 논리

| 계층 | 시점 | 내용 | 근거 |
|---|---|---|---|
| 일별 경보판 | 평일 KST 05:30 스케줄(시장 개장 07:00 전) | 임계 초과 변수만 · 무경보 시 "서명된 무소식" 1줄 · 브리프 HTML은 매일 | 사건형 동인(해협·정책)은 하루 지연도 60일 조달 지평에 유의 |
| 주별 정규판 | 금요일 | 상위 변인 순위·전주 대비·신선도 | 가뭄 모니터 목요일분 포함 · 주간 조달 브리프와 위상 일치 |
| 월별 심층판 | WASDE 발표 익영업일(발표 신규 감지) | 지평×레짐 재산출·인과 재검정·유사 시기 | 순위가 실제로 움직이는 계기는 월별 대형 발표·레짐 전환·소스 편입 |

**실무자 설득 논리 3문장**: ①15개년 표본에 하루치(0.025%)를 더해 바뀌는 순위는 시장 변화가 아니라 수치
불안정이므로 매일 바뀌는 순위는 신뢰를 깎음. ②P90 규칙은 정의상 열흘 중 하루가 초과이고, 임계 5개를 연 250일
평가하면 신호가 없어도 연 100건 이상 발화하므로 **경보는 '사건'이 아니라 '상태'**로 다루고 진입·해제 전이
시에만 통지함. ③유료 LLM 교차검증을 매일 돌리면 비용 전례가 재현됨.

**권고: "생성은 매일, 알림 주기는 수신자 설정"** — 브리프·KPI·유사 시기·서명 스탬프는 매일 갱신(무해), 순위표는
월별 고정, 경보는 전이 시 통지. Power BI 일 임포트에 자동 반영되므로 '3일 요약'은 발행 로직이 아니라 **뷰
필터·메일 다이제스트 설정**으로 구현한다(발행 코드 무변경).
