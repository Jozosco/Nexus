## 1. 확장 방침 (전 에이전트 협의 결론)
`_reference`의 위기·기후 분석 문서들은 2017~ 사례 중심으로 작성됨. **원문 6종을 전면 재작성하는
대신, 본 부록이 2010~2016 구간을 보충**하는 방식을 채택(C-01):
- 원문 재작성은 기존 인용·결론(유사도 점수 등)의 정합성 재검증이 필요해 오류 위험·비용이 큼.
- 부록 방식은 원문 보존(감사 추적) + 15개년 정합을 동시에 충족.
- 각 사례의 정량 수치는 **백필 완료된 15개년 데이터로 재검증 후 확정** — 그 전까지 ⚠️ 초안 표기.

## 2. 2010~2016 주요 사례 보충 (⚠️ C-02 초안 — 데이터 재검증 대상)

### Case P1 — 2010~2011 라니냐·글로벌 식량가격 위기
- 2010 하반기 강한 라니냐 → 남미 가뭄 + 러시아 밀 수출금지(2010.08) → 식용유 동반 급등.
- CBOT 대두유 2010 중반 ~38¢ → 2011 초 ~58¢ 수준까지 상승(약 +50%).
- **현재 유사성**: 라니냐+수출제한의 복합 충격 — ENSO_ONI·수출규제 신호의 결합 효과 검증 사례.

### Case P2 — 2012 미국 중서부 대가뭄
- 2012 여름 미국 옥수수·대두 벨트 반세기 최악 가뭄 → 대두 단수 급감.
- CBOT 대두유 2012.07 ~55¢ 부근 고점. NASA POWER 2012 강수·토양수분 데이터로 정량 재현 가능.
- **현재 유사성**: 기상→수율→압착→가격 체인의 교과서 사례 — Granger ③단계(2012) 지정 근거.

### Case P3 — 2014~2016 공급 과잉·저변동 국면
- 남미·미국 연속 풍작 + 유가 급락(2014~15) → 대두유 ~30¢ 저점권 장기 횡보.
- **현재 유사성**: '하방 레짐'의 대표 표본 — G3 Bear 레짐 학습·저변동 구간 대비에 필수.
  (2017~ 데이터만으로는 상승·위기 사례에 표본이 편중되는 문제를 교정)
