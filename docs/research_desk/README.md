# research_desk — 조사·분석 문서 인덱스

> 조정자 지시(Session 38): 문서를 **월별(작성 시점)** 로 정리. 날짜 없는 상시 참조 문서는 `_reference/`,
> 주제 연속성이 큰 실시간 수집 계열은 `realtime_data_acquisition/` 유지.

## 구조
| 폴더 | 내용 |
|---|---|
| `2026-05/` · `2026-06/` · `2026-07/` | 해당 월 작성 세션 문서(파일명에 날짜 포함) |
| `_reference/` | 날짜 무관 상시 참조(위기 사례·기후·호르무즈 분석 등) |
| `realtime_data_acquisition/` | 실시간·비정형 수집 계열(주제 묶음 — 대체재·비정형 레지스트리·시맨틱·NASA/Comtrade) |

## 규칙
1. 신규 문서는 **파일명에 `YYYY_MM_DD` 포함** → 해당 월 폴더에 저장.
2. 월간 학습(결정·해결)은 `docs/memory_archive/YYYY-MM.md`에 **당월 파일로 기록**.
3. 상시 참조로 승격할 문서는 `_reference/`로 이동.
