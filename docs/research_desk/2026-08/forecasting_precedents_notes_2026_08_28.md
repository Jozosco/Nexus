## 1. ★Temporal Edge Regression — UN 농산물 무역액 예측 (가장 직접적 선례)

**Jiang·Zhang·Poursafaei·Huang (Cambridge·McGill·Mila), UN Trade 데이터셋.**
국가 간 식품·농산물 무역액을 동적 그래프의 엣지 회귀로 예측 — **우리 관세청·GATS
무역 흐름과 동일 도메인**이다.

### 핵심 발견 (원표 실측)
- **Persistence Forecast(마지막 관측값)가 모든 GNN을 이겼다**: Positive MSE
  0.104(노드 정규화) vs 최고 GNN(TGN) 3.96 — 약 38배. 분류 과제도 Persistence
  61.0% vs TGN 32.2%(정확도). 저자들 스스로 "existing GNNs are not sufficiently
  effective"로 결론.
- GNN 중에서는 TGN(메모리 모듈+시간 주의)이 최선. 학습 시 부정 엣지 비율이 성능을
  크게 좌우.
- **log 정규화**가 무역액(국가 간 수십~수십억 달러 스케일 혼재)에서 GNN 학습을
  가장 안정화.
- **node-degree 정규화** = 절대액 대신 **"국가 수출액 중 상대국 비중"을 예측**하는
  관점 전환 제안.

### Nexus 반영
1. **기준선 독트린의 도메인 직접 실증** — "무역 흐름 예측에서 마지막 관측값 이월은
   매우 강한 기준선"이 우리와 같은 데이터(UN 농산물 무역)에서 학술 확인됨.
   G1/G2에 무역 흐름 파생 변수를 넣을 때 **as-of 최근값 이월(현행 mart 동작)이
   이미 강한 예측자**라는 뜻이며, Challenger가 이를 못 이기면 승격 없음(C-014 §4)
   원칙의 외부 근거.
2. **GNN 도입 보류 3중 정합** — 본 논문(GNN이 기준선에 패배) + SC-RIHN(요구 데이터
   부존재·부록 11차) + D-025(Neo4j 선행조건 미충족). 그래프 계열은 Phase B 재검토
   대상으로 통일.
3. **log 변환** — 관세청·GATS 무역액을 피처로 파생할 때 log1p 변환을 기본 후보로
   (스케일 혼재 완화 — D8 단위 정규화와 병행).
4. **비중 관점 = D-050 접점** — node-degree 정규화의 "비중 예측"은 BL 채널 배분
   prior(관세청 국가별 실적 비중)와 같은 표현이다. H1 프로토타입(9월)에서 채널
   비중의 시계열 예측이 필요해지면 이 정식화를 참조.

## 2. GAS-ATT-LSTM — 계량 변동성 레이어 + 주의 + LSTM 하이브리드

**Astudillo et al., Mathematics 13:2300 (2025).** GAS(Generalized Autoregressive
Score — score-driven 변동성, Creal·Koopman·Lucas 2013) 출력을 원 피처와 concat →
피처 수준 additive attention → (Bi)LSTM. Nasdaq·QQQ·TQQQ·Bitcoin·금·은, 3/5/7일 창.

### 핵심 발견
- 하이브리드가 다수 설정에서 우위(GARCH-GJR-LSTM 등 선행 연구와 정합) — 단
  **"7일 창에서는 단순 GAS-LSTM이 최선 — 구조 복잡성이 항상 이득은 아니다"**를
  저자들이 명시(우리 M-010 정신과 정합).
- GAS는 두꺼운 꼬리·비정상성에 GARCH보다 강건하다는 주장(t-분포 score 갱신).
- 상품(commodities) 검증은 future work로 남김 — **대두유 미검증**.

### Nexus 반영
1. **즉시 실행 가능(무료·기자산 확장)**: "변동성 예측을 후단 모델의 입력 피처로
   주입" 패턴 — 우리 스택에서 **EGARCH-X의 조건부 변동성 σ̂_t를 Quantile LightGBM의
   입력 피처로 추가**하는 실험으로 번역된다. 현행 M-009 스택은 EGARCH-X와 분위수
   모델이 병렬인데, 이 논문 계열은 직렬 결합(변동성→피처)의 추가 이득을 시사.
   G2 개발 시 피처 1개 추가 실험으로 검증 비용이 낮다. (walk-forward fold 내
   재적합 필수 — 전 구간 σ̂ 일괄 산출은 누수)
2. **GAS-t 자체는 Challenger 검토 목록 등재**(MTGPR과 동급 지위): EGARCH-X 대비
   개선 여부는 동일 fold 비교로만 판단. ⚠️ Python 표준 구현 부재(arch 미지원) —
   구현 비용이 있어 우선순위는 σ̂ 피처 실험보다 낮음.
3. Bi-LSTM·attention 부분은 기존 Challenger 목록(GRU/LSTM 계열)에 이미 포괄 —
   신규 등재 불요.

## 3. 트리 기반 원자재 가격 예측 자동화 파이프라인 (ACK 2024 — 이은지·유헌창, 고려대)

니켈 가격 XGBoost: 결측 보간→ADF 기반 차분 자동화→변수 조합 전수 탐색(2^8)→
그리드서치, 단변량·다변량 병렬 제시. MAPE 0.2%·R² 0.99 보고.

**정직 판정 — 배경 참고(신규 채용 요소 없음)**:
- 자동화 구성(전처리→학습→시각화)은 Nexus 파이프라인이 이미 상회(as-of 게이트·
  C-08 품질 게이트·walk-forward가 이 논문에는 없음).
- **MAPE 0.2%는 1-step 예측 특성상 persistence와의 격차가 불명** — 나이브 기준선
  비교 부재, 차분·그리드서치의 시계열 분할 누수 방지 서술도 없음. 수치 인용 금지.
- 참고할 소품: 단변량 vs 다변량 결과 병렬 제시는 G2 보고서의 "기준선 대비" 표와
  같은 취지 — 이미 우리 Validation Protocol §3에 있음.

## 4. GCN 공급망 수요예측 (Sustainability 2024 — 쓰촨대)

기업=노드·관계=엣지·수요=엣지 피처의 GCN, ARIMA/SVR/MLP/LSTM 대비 우위 주장.
**Phase B 배경** — 요구 데이터(다계층 기업 간 수요망)가 Nexus에 없음(SC-RIHN과
동일 판정). 국가 수준 무역 그래프로의 전용은 #1 논문이 이미 부정적 근거 제공.

## 5. PI-GNN 공급망 교란 (FAPM 2025) — 인용 주의

물리 제약(흐름 보존·용량·리드타임)을 손실 정규화로 주입하는 PINN 계열 개념.
**⚠️ 인용 주의 등급**: 신생 저널·교신저자 개인 메일·참고문헌에 무관 항목 혼입 —
학술 신뢰도 검증 불가. 개념 자체(도메인 제약을 학습에 주입)는 정당한 문헌
계열(Raissi PINN)이며, Nexus에서는 이미 **as-of 게이트(시점 제약)·분위수 교차
방지·물리 범위 가드(ENSO ±5, ZL 5~200 USc/lb)**로 같은 원리를 구현 중.
이 문서 외 인용 금지 — 원리 확인용으로만 보관.
