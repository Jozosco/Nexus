# 비정형 데이터 일별 수집·온톨로지 반영 실사 — 조정자 재확인 답변

**작성**: C-01 × P1-06 합동 감사 · 2026-08-25

## 한 줄 결론

**일별 수집은 실제 가동·축적 중입니다**(8/17~8/24 실증). 그러나 **온톨로지 갱신은 전량
수동 큐레이션**이며, 일별 신호가 온톨로지 후보로 흐르는 자동 경로는 없었습니다 —
"승격 수동"은 설계 의도(S-1)이지만 **"후보 큐 부재"는 미구현 갭**으로 판정,
**당일 무료 해소 완료**(하단 §4).

## 1. 수집 실태 (실측)

| 계층 | 주기 | 실측 |
|---|---|---|
| Perplexity 프록시 신호(7분류 22지표) | **일별**(KST 평일 05:30) | ✅ 가동 중 |
| 일별 영구 아카이브(A-181) | 일별 append+커밋 | ✅ **62행·6일자(8/17~24) 축적 실증** — 단 22종 중 **12종만** 축적(해협 AIS 4종·운임 2종·기상 2종 등은 0건 — 수집 실패로 추정, §5) |
| GAIN·FAO 요약 코퍼스(온톨로지 구축의 실제 원천) | **수동**(workflow_dispatch 전용) | ⚠️ 일별 아님 — 원문 발행 자체가 월간·수시(설계상 분리, A-090) |
| UNSTR_* 월별 시계열 | 월 단위 | ⚠️ 스크립트는 매일 돌지만 입력이 수동 코퍼스 실행 시에만 갱신 → 사실상 정적 |

→ 질문 전반부 답: **일별 수집은 되고 있으나**, "온톨로지 구축에 쓰인" 코퍼스(GAIN/FAO)와
일별 프록시 신호는 **별개 파이프**입니다.

## 2. 온톨로지 반영 판정 — 수동 큐레이션 (자동 파이프 없음)

- ontology.yaml 갱신 이력 3커밋 전부 수동 편집. 쓰기 스크립트 0개(검증기만 존재)
- signal_tag_mapping 브리지는 **월별 UNSTR_* 계열 전용** — 일별 12종 지표는 시맨틱
  레이어 전체에서 미등재(시차 갭: 시맨틱 v3 확정 8/13-14 → 일별 아카이브 신설 8/16)
- P1-06 승격 계약(candidate → 도메인 검증 서명+evidence → validated)은 성문화돼
  있으나 **후보를 생산하는 입구가 없었음**

| 판정 | 분류 |
|---|---|
| 승격이 수동인 것 | **설계 의도** — S-1(미검증 엣지 자동 승인 금지), 유지 |
| 후보 큐(입구) 부재 | **미구현 갭** — 해소 대상 |
| 일별 12종 시맨틱 미등재 | **시차 갭** — 해소 대상 |

## 3. 적용한 해소 방법 + 근거 (원칙 ② — 전부 무료·기존 자산)

| # | 조치 | 방법 | 근거 |
|---|---|---|---|
| 1 | **온톨로지 후보 큐 자동 생성** | daily_unstructured_digest.py에 `_emit_ontology_candidates()` — 임계 초과 신호(호르무즈≥2·수에즈≥2·미중≥2·GeoIntel≥60·GPR≥200)를 event_schema의 MarketEvent(`review_status: extracted`)로 `data/semantic/events/candidates_{일자}.json` 적재. note 발췌가 evidence 계약(S-5) 충족 | **자동화는 후보 발견·적재까지만** — 승격은 P1-06 수동 검증 유지(S-1 무위반). 기존 C10 게이트가 무료 검증. scratchpad 검증: 임계 초과 2건만 적재·미달 제외 확인 |
| 2 | **매핑 브리지 확장** | ontology.yaml signal_tag_mapping 6개 태그에 `daily_codes` 필드 — 일별 12종 중 11종을 기존 한글 태그에 연결 | 시차 갭 해소 — 신규 태그 없이 기존 체계에 연결(최소 변경) |
| 3 | **검증기 C12 신설** | validate_semantic_layer.py에 daily_codes 중복·실존·미배정 교차 검사 | 재발 방지 게이트 — 첫 실행에서 미배정 11종을 정확히 경고(수집 실패 카테고리와 일치 — 게이트 실효 즉시 확인) |
| 4 | 후보 큐 영속화 | digest 커밋 스텝에 data/semantic/events 경로 추가 | A-181 커밋 선례 준수 |
