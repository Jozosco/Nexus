## G1 — 핵심 변인 + 과거 유사 시기 실측 참조 (★8/31 Preview)

### 산출물이 이렇게 달라짐
구 산출물(변수 중요도 보고서 단일)이 **일일 브리프 중심의 3계층 발행**으로 재편되고,
재정립(D-051)에 따라 "과거 유사 시기 실측 참조"가 브리프의 본질 블록이 됨:

| 블록 | 개정 전 | 개정 후 (v5 · 실코드 동기화 완료) |
|---|---|---|
| 유사 시기 참조 | 없음 | 경보·상위 변인의 표준화 지수가 현재와 같던 과거 거래일들의 **약 1주/1개월/3개월 후 실측 분포**(2010~) + 위기 사례 배지 |
| 사례 메커니즘 서사 (R1) | 없음 | 배지 클릭 → 원인 사건→전달 경로→가격 실측→현재와의 유사점/차이점 (예: Case 3의 'COVID·흑해發 경로 차질→우회·보험료→도착가 상방' 구조가 호르무즈 국면과 동형) |
| 변곡점-원인 연동 (R2) | 없음 | 90거래일 내 급변일 상위 4일 차트 마커 ①~④ + 클릭 시 당시 기사·변인 상태·온톨로지 경로 |
| 수치 최신성 | 목업 08-10 (커밋 CSV 한계) | 실발행은 **매일 CME 정산가**(런 #83 실증 — 사상 첫 전체 초록 런·브리프 첫 실발행) |
| 경보 문안 | 임계·z-점수 등 | 국문 자연화 계약(기준·표준화 지수) + 화면 금지 용어 자동 검증 |

### 감사 해소(A-239)가 G1에 주는 것
- **해석 규율이 실행 지점에 설치됨**: CE-015 해석 규칙(대두유−팜유 가격 차이의
  평균회귀 가정 금지 — 2020년 이후 공행성 붕괴)이 온톨로지에 주입되어, 경보 문안과
  대체 검토 서술이 근거 사슬을 갖게 됨. 브리프의 경보 "판단 근거"가 이 규칙을 인용.
- **유사 사례 서사의 근거 강화**: 미·브·중 삼각무역 20년 실측(2018 관세: 미국 對중
  60%→18%·브라질 82%)이 CE-011 evidence로 등재 — Case D(미·중 관세, 유사도 9/10)
  서사의 정량 기반.
- **D-047 브리프 신뢰 상승**: errata의 해바라기 러/우 배분 항목이 WMT 원표 대조로
  해소(브리프가 정확했음 확정) — 상시 참조 문서의 열린 의문 1건 감소.

### 데이터 승인 반영
- **ZM·ZS(9/1 승인)** → 압착 마진(Board Crush) 스냅샷 행이 "수집 예정"에서 실측으로
  전환 — 트레이더가 대두 복합체를 읽는 대표 지표가 브리프에 편입. farmdoc P3 원문
  판독(오일 가치 비중 25~35%→35~50%)이 이 변수의 설계 근거로 확정됨.
- 무료 4건(ZC/ZW 곡물·PSD 유종 분해·MPOB·COT)은 자율 실행 — COT는 금융화 논문이
  학술 근거(G1-5).

### 남은 것 (8/31 전)
내일(토) 05:30 KST 리허설 런이 **완전판 판정** — 유사 시기 블록·참고 도착가 범위의

## G2 — 확률 가격 밴드 (★9/10 Preview)

### 산출물이 이렇게 달라짐
- **산출물 계약은 불변**(P10~P90 분위·레짐별 coverage — M-009 설계 확정), 구현이
  9/10 목표. 그 전까지 브리프의 "참고 범위"가 자리를 지키며, **산출 근거 패널이
  그대로 교체 지점**(G2 가동 시 기준 가격층만 분위수 모델로 교체 — 화면 구조 유지).
- **Champion–Challenger 규율 복원**: '등재 주장만 있던' MTGPR·GAS-t가 정본 목록
  (modeling.md·c03 §4·모델 포트폴리오)에 '검토 대기'로 실등재 — 사전 등록 원칙
  (M-009)이 문서 실물로 복원됨. 승격 게이트에 무역 흐름 Persistence 특칙 신설.
- **변동성 층 보강 경로 확정**: EGARCH-X σ̂ → Quantile LGBM 피처 주입 실험(부록
  12차 채용)이 데이터 계획 G2-3에 등재 + **ZL 옵션 IV(9/1 승인)** — 내재 변동성이
  실측 변동성 층을 보완.
- **레짐별 coverage 보고의 학술 근거 명문화**: Heliyon 꼬리 동조화(극단 분위수
  연결성 91%/87%)가 Validation §7에 인용 — 스트레스 구간 분리 보고가 왜 필수인지의
  근거.

### 남은 것
G2 구현 착수(9월 초) — Azure ML 경로는 클라우드 이관 예고(DQ-11 — AWS+Snowflake)
