# 하이브리드 방법론 설계 — Black-Litterman 결합 (조정자 지시 2026-08-25)

**작성**: C-03 주관 · C-01 종합 · **참고 원문**: `references/CIKM_2025_LLM_enhanced_BlackLitterman.pdf`
(Lee et al., CIKM'25 FinAI — 한국 연구진: Elice·Meritz·미래에셋·UNIST)
**전제**: 기존 스택(M-009 — G1 Elastic Net+SHAP / G2 SARIMAX+Quantile LGBM+EnCQR /
G3 Markov+HITL)을 **대체하지 않고 그 위에 결합 계층을 얹는다**. 승격은 C-014 §4 게이트.

## 0. Honeycomb Model — ❓ 확인 요청 (정직 표기)

조정자가 후보로 언급한 "Honeycomb Model"은 **첨부 파일 2건 전문 검색에서 발견되지
않았습니다**(언급 0건). 금융 예측·자산배분 문헌에서 표준 용어도 아니어서 추측으로
설계에 넣지 않았습니다 — **출처(파일 또는 링크)를 공유해 주시면 즉시 통합 검토**합니다.
본 설계는 Black-Litterman(이하 BL) 축으로 우선 구성했습니다.

## 1. 왜 BL이 이 프로젝트에 맞는가 — 그리고 어디에 맞는가

BL의 본질: **시장 균형(prior)에 '뷰(주관적 전망)'를 불확실성 가중으로 베이지안
결합**해, 뷰가 강할수록·확실할수록 posterior가 뷰 쪽으로 이동. 원논문은 주식
포트폴리오 배분용이지만, 이 **결합 문법** 자체가 우리 프로젝트의 두 지점에 정확히
대응합니다:

### 적용 A — 원산지 채널 배분 (BL의 직접 적용 · 차별화 축 ① 시장구조)

조달 실무의 실제 질문은 "가격이 오를까"만이 아니라 **"어느 채널에서 얼마나
확보할까"** — 원산지 채널(US·AR·BR·VN·CN + 대체유 채널)을 BL의 '자산'으로 보면
자산배분 문제가 됩니다.

| BL 구성요소 | 우리 대응물 (전부 확보/수집 중 데이터) |
|---|---|
| 시장 균형 prior | **한국 전체 수입의 국가별 실적 비중**(관세청 GW 16 HS × 10개국 — 외부 공개 통계라 D-021 위반 아님) + 채널별 실측 CIF 수준 |
| 기대수익 → 기대비용 | 채널별 도착가 분포(G2 밴드 + 내재 잔차층 — D-041 기반) — 부호 반전(비용 최소화) |
| 공분산 | 채널 CIF 간 공분산(월별 실측 2010~) + 유종별 수급(D-049 수집분)으로 보강 |
| **뷰(Q)** | CE 인과 엣지 발화: 예) Decree 423/2026(아르헨 수출세 인하) → "AR 채널 상대 비용 하락" 뷰 · 미 RVO(CE-022) → "US 채널 물량 리스크" 뷰 · VAL 가동 → "VN 채널 확대" 뷰 |
| **뷰 신뢰도(Ω)** | P1-05 ABSA 스펙의 **S+Confidence 필드(기존재)** + 엣지 status(validated > candidate) + GPT 교차검증 판정 |
| 산출 | **채널 배분 권고 + 각 뷰의 기여 분해**(어떤 근거가 배분을 얼마나 움직였나 — 설명가능성 내장) |

이것이 경쟁사(기상·선물 데이터 중심)가 하지 않는 **차별화 축 ①②③의 정량 통합**입니다:
시장구조(채널·기업) × 에너지 정책(SAF·RVO 뷰) × 지정학(GPR·호르무즈 뷰)이 하나의
배분 프레임에 결합됩니다.

### 적용 B — G2 분포의 뷰 보정 계층 (BL의 문법 적용)

G2 통계 분포(SARIMAX+Quantile LGBM) = prior, 이벤트·정성 신호 = 뷰 → **보정된 예측
분포**. 예: 호르무즈 위협 2단계 발화 시 "60일 상방 뷰(신뢰도=프록시 등급)"가 P90
꼬리를 넓힘. EnCQR 보정은 뷰 결합 **이후** 최종 단계에서 적용(커버리지 보장 유지).

## 2. LLM-Enhanced BL 논문의 채용 지점 (정직 평가 포함)

논문의 기여: LLM의 수익 예측 + **예측 불확실성(반복 샘플링 분산)** 을 Q·Ω로 변환하는
체계 + "LLM 선택 = 특정 편향의 매니저 선택"이라는 실증.

**채용**: ①뷰 생성 파이프라인 구조(예측→불확실성→Q·Ω 변환식) ②look-ahead 차단
설계(모델 컷오프 < 평가 기간 — 우리 as-of 규율과 동일 철학) ③복수 LLM 뷰 스타일
차이를 **교차검증 라인(GPT-5.6 병행)** 으로 흡수.

**경계(무단 채택 금지 사유)**: ①대상이 S&P 50 주식·2주 리밸런싱 — 상품 조달과 도메인
상이 ②13개월 백테스트는 짧음(우리 기준 stress slice 검증 불충족) ③LLM 자유 예측의
누수 통제는 우리 환경에서 재검증 필요. → **뷰 생성기의 1차 소스는 LLM 자유 예측이
아니라 검증된 CE 엣지·ABSA 신호**(구조화된 근거 우선), LLM은 뷰 문장화·신뢰도 보조.

## 3. 하이브리드 전체 구조 (기존 스택과의 결합도)

```
[G1] 동인 중요도 ──────────┐  (뷰 후보의 변수 근거)
[G2] 확률 밴드(prior) ─────┤
[CE 엣지·ABSA·일별 신호] ──┼─→ [뷰 생성기 Q·Ω] ─→ [BL 결합]
[GPT 교차검증 판정] ───────┘         │                 │
                                     ↓                 ↓
                      적용 B: 보정된 예측 분포   적용 A: 채널 배분 권고
                                     ↓                 ↓
                              [EnCQR 커버리지 보정] [G3 레짐·HITL 게이트]
                                     └────── 인간 승인 후에만 실행 ──────┘
```

## 5. 실행 단계 (마일스톤 무간섭)

| 단계 | 시점 | 내용 | 게이트 |
|---|---|---|---|
| H0 | ~9/10 | 설계 동결(본 문서) — G1 8/31·G2 9/10에 **미개입** | — |
| H1 | 9월 중 | **적용 A 프로토타입**: 관세청 실측 prior + 수동 뷰 3종(아르헨 세제·RVO·VN)으로 채널 배분 1회 산출 — 과거 3개 사건 재현 검증 | 사건 검증 + GPT 교차검증 |
| H2 | 9월 하순 | 적용 B: G2 Preview 분포에 뷰 보정 결합 — EnCQR 후단 유지 | C-014 §4(4 horizon 중 3 개선 등) 통과 시만 승격 |
| H3 | Phase B | LLM 뷰 자동화(P1-05 정형화와 동시) — 복수 모델 교차 | 동상 + HITL 상시 |

**필요 승인(R-021 ③)**: H1 착수 승인(9월 초 — G2 Preview 리소스와 병행 가능 여부는
9/3 분위수 모델 1차 결과 후 판단 권장). Honeycomb 출처 공유.

## 6. 정직 경계 요약

- BL posterior는 **권고 산출물** — Buy/Hold·배분의 실행은 항상 HITL(CLAUDE.md §6)
- prior의 "시장 균형"은 주식처럼 자연스럽지 않음 — 국가 실적 비중 prior의 한계
  (과거 구조 반영)를 명시하고 τ(prior 신뢰도)를 보수적으로
- 뷰가 없으면 prior 그대로 = **뷰 없는 날은 배분 변경 권고 없음**(과잉 신호 방지)
- 모든 뷰는 evidence(원문 발췌) 필수 — S-5·EvidenceSpan 계약 그대로
